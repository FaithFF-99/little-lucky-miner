# 小小矿工 · 和你一起过的小日子

[打开游戏](https://faithff-99.github.io/little-lucky-miner/homeward.html)

手机浏览器直接打开，点击画面下钩。25局，每局30秒，每3局换地貌；最后一站是花海山谷。

- 钩子摆动比上版慢约38%（比上一档慢速微调快约10%），收回后从原角度继续，不突然跳转。普通抓取只更新收入统计，金币数字在左上角轻轻浮起；空钩不弹提示。
- 漏掉的所有问号袋下一局继续出现，可和该局的新袋子一起抓。五只狗狗不重复增加：金毛漱口水、西高地牙膏、西高地牙刷、哈士奇牙线、金毛牙签，初次出场局数为1/4/9/13/17。
- 第2局放小家钥匙，第3局起回家；第4局额外放种田技能袋；第21局起可获得狩猎技能。
- 家、农场和商店均可分别操控矿工与伴侣。点小人或摇杆旁的按钮切换，再用摇杆移动；选中者脚下有圆环，人物头顶没有身份文字。
- 两间卧室（主卧、客卧）和狗狗房。走近床边后，会先走到窗边，再躺下睡30秒；可同睡主卧，也可各睡一间。同床入睡会弹出「爱你，明天见，晚安」；分房睡觉会触发「happy wife happy life」「别生气了嘛～」。
- 靠近狗狗可投喂，或把它抱起，送到右上角狗狗房的专属狗窝睡30秒。
- 种地是独立场景；走近田地播种和收获，走到车旁去商店，走近柜台挑选种子或卖菜。开车免费。
- 六种作物均可做饭。可以单独做，也可以邀请另一位一起做：每人消耗1份收成，8秒后各得到2份餐食。做好后自动走到餐厅椅子旁坐下，吃完一份（8秒）才增加一次喂狗狗的机会；一起做用2份收成得到4份饭，两个人吃完剩2份可喂狗狗。喂食4次达到Lv.3成年。
- 走近沙发可以独自或邀请另一位一起坐下看电视；摇杆移动即可站起。人物的站姿、坐姿和动作各不相同。
- 卫生间可以洗澡（20秒）和如厕（8秒），两个人也能同时洗澡，包含冲水、洗头、搓泡泡和冲洗动作。里面有人时，另一位推门会听到「再等一下！」，仍可以继续推门进入。
- 家中走近后发现做饭、浇水、冰箱纸条和电视。电视随机出现「I love you」「爱你」「今天辛苦了」「今日黄金段播放《我可能不会爱你》」，连续两次不重复同一频道；这里展示的是文字彩蛋，不提供电视剧视频。
- 成年狗狗和狩猎技能齐备后可以开启狩猎模式、选择同伴；狩猎地图将在后续版本加入。
