# 小小矿工 · 回家种田的25段旅程

[打开新版游戏](https://faithff-99.github.io/little-lucky-miner/homeward.html)

手机浏览器直接打开，点击画面下钩。共25局，每局30秒；每3局更换地貌，最后一局是花海山谷。

- 九种地貌：草原、峡湾、丹霞、雨林、沙丘、雪山、火山、群岛、花海。
- 只有五只狗狗：金毛漱口水、西高地牙膏、西高地牙刷、哈士奇牙线、金毛牙签。分别安排在第1、4、9、13、17局的问号袋，下一局加入。未抓到的奖励后续重现，不会重复送宠物。
- 第2局问号袋放小家钥匙，第3局可回家；第6局放种田技能；第21局放狩猎技能。未获得的技能优先补发，不是每局都有问号袋。
- 家里可拖动虚拟摇杆或点空地行走，墙壁与家具会挡路。走近狗狗才出现投喂，走近床边才可休息30秒。宠物可以跟随、散步、停留。
- 家具藏着小惊喜：打开电视可看见「I love you」、❤️、「一起看电视很开心哦！」；打开冰箱有「要按时吃饭哦～」；阳台植物可以浇水，照顾过的叶子会更鲜亮。
- 页面默认收起地图、背包和玩法资料，回家后通过走近探索互动。矿石按不规则位置散落，每局都不同。
- 免费开车去商店，使用挖矿金币购买种子。收成可卖出，或靠近厨房做饭。1份收成做2份炖菜，矿工先吃1份才能喂狗狗1份。每只喂4次到Lv.3成年。
- 狩猎技能与成年伙伴齐备后，可以选择伙伴开启狩猎模式；狩猎副本地图将在后续版本加入。
- 黄金50/100/200、钻石300金币；胡萝卜种子25/回收40，小番茄50/85，南瓜80/140，分别45/75/120秒成熟。所有金额是游戏内金币，不涉及支付。
- 空钩不提示；普通财物只在本局收入区域显示价值，不遮挡钩子、不闪烁。
- 离开矿洞、弹窗或切到后台时挖矿暂停；睡眠和作物生长按真实时间计算。
- 自动保存到当前浏览器。新版使用独立存档，可手动导入本机旧旅程；朋友通过链接不会获得你的存档。

`homeward.html` 包含全部代码、样式和像素绘图，无外部依赖。旧根地址将改为停用提示页，不自动跳转。
