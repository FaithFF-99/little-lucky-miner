# 小小矿工 · 和你一起过的小日子

[打开游戏](https://faithff-99.github.io/little-lucky-miner/homeward.html)

手机点开即可玩。25局、每局30秒、每3局换地貌。问号袋漏抓后会在下一局补上。只有五只狗狗：金毛漱口水、西高地牙膏、西高地牙刷、哈士奇牙线、金毛牙签。

第2局小家钥匙，第3局起回家；第4局种田技能，第21局狩猎技能。家、农场和商店中分别选择人物，用摇杆或点击空地移动，靠近家具和狗狗才出现动作。人物头顶不显示身份文字。

## 这次新增的日常

- 人物睡眠60秒，同床说「爱你，明天见，晚安」。分房睡随机有三种故事：原来的「happy wife happy life」「别生气了嘛～」、爬起来抱狗去她的床上、收起自己房间的床后抱狗去找她。到达后两人和小狗一起睡60秒，狗狗说「进入甜美的梦乡」「和粑粑麻麻一起睡」。任何一个人走近床板都能重新装床，组装免费。狗窝独自休息仍为30秒。
- 客厅桌上原本是空花瓶。商店购买香水百合90、玫瑰60、茉莉花45金币，一次购买后可一直摆放，靠近花瓶可切换拥有的花。
- 阳台每盆单独累计浇水，每次间隔60秒；第11次长大结果，之后浇水继续结果，树上最多留3颗。靠近摘果，可直接吃，也可冷藏。
- 靠近冰箱可存放/取出餐食、六种收成与果子，库存守恒。随机纸条：「要按时吃饭哦～」「今天你开心吗？」「今天也要吃的饱饱的哦」「哇塞，冰箱里好多吃的」。
- 电视共7个文字频道，新增「恶作剧之吻」「八仙」「奥德赛」；保留原来的爱意文案，连续两次不重复频道。
- 第25局商店可以买1200金币的戒指。回家靠近对方送戒指，说「marry me」，接受后打开野战副本入口；仍需原有狩猎技能和一位Lv.3成年狗狗同行。

## 双人野战狩猎

原创像素野战场景，90秒击退6只野猪。选择任意人物摇杆移动，另一位在远处时跟上；点击空地也能行走。点击或长按射击，会攻击235像素内最近的目标；电脑也可用空格。蓝色补给箱恢复25体力，石垒挡路，需要绕行。首次通关600金币，再次180金币，每次另得小麦、水稻各2份。失败不扣金币，可重试；退出/刷新会结束本次野战，已结算奖励保留且不重复发放。

## 原有生活玩法

两间卧室和狗狗房，窗边再到床边的睡觉路线；走近狗狗可投喂或抱去专属狗窝。六种作物均可做饭，每人1份食材做2份饭，用时8秒；单人/双人做完都会去餐厅坐下吃饭，8秒吃完才获得喂食机会。喂4次达到Lv.3成年。可以坐沙发看电视、双人洗澡（20秒，含动作）和如厕（8秒）；里面有人时会说「再等一下！」，仍可继续推门。
