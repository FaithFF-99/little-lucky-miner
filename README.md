# 小小矿工 · 和小伙伴一起生活

[打开游戏](https://faithff-99.github.io/little-lucky-miner/)

一个无需安装的手机像素小游戏。点击屏幕下钩挖宝，也可以用电脑空格键。

- 21 局，每局 60 秒，每 3 局切换一片地貌：草原、峡湾、丹霞、雨林、沙丘、雪山和星夜火山。
- 问号袋里是小猫、小狗等宠物，从下一局开始陪伴；可以跟随、自由散步或停留。
- 第 7 局结束后解锁三房两厅的家，点地面行走，走到床边休息 30 秒。
- 第 14 局结束后解锁农场。免费开车去种子铺，用挖矿金币购买种子，播种、收获、卖菜。
- 金块 50 / 100 / 200 金币，钻石 300 金币。胡萝卜种子 25、回收 40；小番茄 50、回收 85；南瓜 80、回收 140。所有金额均为游戏内金币。
- 挖矿在离开矿洞、打开弹窗或切到后台时暂停；作物生长和睡眠使用真实时间。
- 进度保存在当前浏览器，不会通过分享链接同步。支持在链接里藏一句温暖的话。

`index.html` 已包含全部样式、像素绘图和脚本，不依赖外部库或服务器接口，可直接通过 GitHub Pages 托管。
